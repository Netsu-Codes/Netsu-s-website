# Netsu-s-website
A small personal website I made about myself ( it started as my first project in stardance!) 
This is the first website I made so it may not be the best to try and re-create but if you're interested this are the resources I used: 

Tutorials:
 ⫸ I followed a tutorial in YouTube by Flickarity (https://www.youtube.com/watch?v=vlDAQXqOqKo&t=2530s) this is where I got the whole "structure" idea from, it was VERY useful and easy to understand 100% worth the 45 minutes of watch time.
 ⫸ While checking the examples of other people I noticed that my URL contained personal information so i followed this tutorial to clean up the URL https://www.youtube.com/watch?v=ZwG9jwit2Ho.
 ⫸ I watched many more tutorials but these are the ones that I ended up using and found the most useful. The other ones I saw weren't beginner friendly At all so I only used those.

Notes:
⫸ If this is your first building a website I STRONGLY recommend you watch tutorials not just W3schools, while W3schools is very useful, it can also be complicated to understand if you don't have any knowledge on website building. Normally tutorials for beginners explain the logic behind things. Its better to lean the "why" rather than just "how" of how something works.
